# Mojo: Talks to the Metal

Mojo is a compiled systems language built by Modular that talks directly to the metal and silicon. It compiles through MLIR down to native machine instructions -- your code maps to CPU SIMD lanes, GPU warps, cache hierarchies, and memory controllers with zero runtime overhead. No VM, no garbage collector, no interpreter sitting between you and the hardware. Python-like syntax, C/Rust-level performance. It is the language powering MAX (Modular's AI engine) and can be used standalone for any systems programming task where you need to squeeze every cycle out of the silicon.

## When to Use Mojo

**Use Mojo when:**
- Writing custom inference engines (GGUF, safetensors)
- Authoring GPU kernels (NVIDIA, AMD) without CUDA boilerplate
- Building performance-critical tensor operations
- Creating FFI bridges to C/C++ shared libraries
- Implementing SIMD-vectorized numerical code
- Replacing Python hot paths with compiled code
- Building components for MAX pipelines

**Use Python instead when:**
- Rapid prototyping with no performance constraints
- Using established ML frameworks (PyTorch, JAX) directly
- Scripting and automation tasks
- The bottleneck is I/O, not compute

**Use Rust/C++ instead when:**
- Building OS-level software (kernels, drivers)
- Need a mature ecosystem with decades of libraries
- Working outside the AI/numerical computing domain

## MANDATORY: Debug-First Development

**Every piece of Mojo code generated by the agent MUST include debug instrumentation.** This is not optional. Debugging in systems-level code is not an afterthought -- it is the difference between a 5-minute fix and a 5-hour hunt.

**Rules the agent MUST follow when generating Mojo code:**

1. **Always import and initialize `DebugLog`** (Section 13) at the top of every module.
2. **Every struct that manages resources** (pointers, file handles, GPU memory) MUST conform to the `Debuggable` trait.
3. **Every `UnsafePointer.alloc()` call** MUST be paired with a `debug_log` call logging the allocation address and size.
4. **Every `ptr.free()` call** MUST be preceded by a `debug_log` confirming the free.
5. **Every FFI call** (`DLHandle`, `external_call`) MUST log the symbol name and return status.
6. **Every GPU kernel launch** MUST log grid dims, block dims, and shared memory size before dispatch.
7. **Use `debug_assert`** for invariant checks that should crash in debug builds but vanish in release.
8. **Build with `--debug-level=full -O0`** during development. Only switch to `-O3` for benchmarking/release.
9. **Set `MOJO_ENABLE_STACK_TRACE_ON_ERROR=1`** in every development environment.

The debug overhead is **zero in release builds** because all logging is gated behind `comptime if` on a compile-time `alias DEBUG`.

## 1. Language Fundamentals

### 1.1 Functions: `def` vs `fn`

As of v26.2+, `def` is the standard function keyword. `fn` is deprecated but still compiles.

```mojo
# Standard function -- non-raising by default
def add(a: Int, b: Int) -> Int:
    return a + b

# Function that can throw errors must declare `raises`
def divide(a: Float64, b: Float64) raises -> Float64:
    if b == 0.0:
        raise Error("division by zero")
    return a / b

# Void return -- omit the arrow
def greet(name: String):
    print("Hello, " + name)
```

**Key rules:**
- All arguments require type annotations (no implicit `object` types)
- `raises` must be declared if the function can throw
- Return type goes after `->` (optional for void functions)

### 1.2 Variables

```mojo
# Mutable variable
var x: Int = 42
var name = "Mojo"  # Type inferred as String

# Compile-time constant
alias MAX_BUFFER = 4096
alias PI: Float64 = 3.14159265358979
```

- `var` -- mutable, runtime value
- `alias` -- compile-time constant, fully folded by the compiler

### 1.3 Ownership and Argument Conventions

Mojo has three argument conventions that control how values are passed:

| Convention | Syntax | Mutability | Ownership Transfer |
|:-----------|:-------|:-----------|:-------------------|
| **Borrowed** | `arg: Type` (default) | Immutable reference | No |
| **Mutable ref** | `inout arg: Type` | Mutable reference | No |
| **Owned** | `owned arg: Type` | Full ownership | Yes |

```mojo
# Borrowed (default) -- read-only access
def print_length(data: String):
    print(len(data))

# Inout -- mutate the caller's value in place
def increment(inout value: Int):
    value += 1

# Owned -- take ownership, caller can no longer use it
def consume(owned buffer: List[Int]):
    # buffer is ours now, will be destroyed when we return
    print(len(buffer))

# Transfer sigil: ^ signals "I'm done with this, take it"
var buf = List[Int](1, 2, 3)
consume(buf^)  # Ownership transferred -- buf is dead after this line
```

**When to use each:**
- **Borrowed**: Default. Use for read-only access. Zero-cost.
- **Inout**: When you need to modify the caller's value.
- **Owned**: When the function should take full control of the value (e.g., moving into a container, destructor patterns).

### 1.4 Value Semantics and Lifecycle

Mojo types use value semantics by default. Every variable exclusively owns its value.

```mojo
struct Tensor:
    var data: UnsafePointer[Float32]
    var size: Int

    # Constructor
    def __init__(out self, size: Int):
        self.size = size
        self.data = UnsafePointer[Float32].alloc(size)
        memset_zero(self.data, size)

    # Copy constructor -- deep copy
    def __copyinit__(out self, existing: Self):
        self.size = existing.size
        self.data = UnsafePointer[Float32].alloc(existing.size)
        memcpy(self.data, existing.data, existing.size)

    # Move constructor -- steal resources
    def __moveinit__(out self, owned existing: Self):
        self.size = existing.size
        self.data = existing.data
        # existing is now hollow -- no double free

    # Destructor
    def __del__(owned self):
        self.data.free()
```

**Lifecycle methods summary:**
| Method | Purpose | When Called |
|:-------|:--------|:-----------|
| `__init__` | Construct new instance | `var x = Type(...)` |
| `__copyinit__` | Deep copy | `var y = x` (when x still used) |
| `__moveinit__` | Move (steal internals) | `var y = x^` (transfer) |
| `__del__` | Cleanup resources | Value goes out of scope |

**ASAP Destruction**: Mojo destroys values as soon as they are no longer referenced, not at scope end. This is critical for resource management.

## 2. Type System

### 2.1 Structs

Structs are the primary custom type mechanism. They are stack-allocated, statically-typed, and fully compile-time bound.

```mojo
struct ModelConfig:
    var hidden_size: Int
    var num_heads: Int
    var vocab_size: Int
    var dtype: DType

    def __init__(out self, hidden: Int, heads: Int, vocab: Int):
        self.hidden_size = hidden
        self.num_heads = heads
        self.vocab_size = vocab
        self.dtype = DType.float32

    def head_dim(self) -> Int:
        return self.hidden_size // self.num_heads
```

### 2.2 Traits

Traits define contracts that structs must implement.

```mojo
trait Tokenizable:
    def tokenize(self, text: String) -> List[Int]: ...
    def detokenize(self, tokens: List[Int]) -> String: ...

trait Serializable:
    def to_bytes(self) -> List[UInt8]: ...
    def byte_size(self) -> Int: ...

# Struct conformance
struct BPETokenizer(Tokenizable):
    var vocab: Dict[String, Int]

    def tokenize(self, text: String) -> List[Int]:
        # implementation
        ...

    def detokenize(self, tokens: List[Int]) -> String:
        # implementation
        ...

# Trait composition with & operator
def process[T: Tokenizable & Serializable](item: T):
    var tokens = item.tokenize("hello")
    var bytes = item.to_bytes()
```

### 2.3 Parametric Types (Generics)

Mojo distinguishes between **parameters** (compile-time, in `[]`) and **arguments** (runtime, in `()`).

```mojo
# Parametric struct -- type and size known at compile time
struct FixedBuffer[dtype: DType, size: Int]:
    var data: SIMD[dtype, size]

    def __init__(out self):
        self.data = SIMD[dtype, size](0)

    def __getitem__(self, idx: Int) -> Scalar[dtype]:
        return self.data[idx]

# Parametric function
def matmul[M: Int, N: Int, K: Int](
    a: FixedBuffer[DType.float32, M * K],
    b: FixedBuffer[DType.float32, K * N],
) -> FixedBuffer[DType.float32, M * N]:
    ...

# Usage -- parameters in [], arguments in ()
var buf = FixedBuffer[DType.float32, 256]()
```

**Parameter expressions** can include any compile-time computable value:
```mojo
alias BATCH = 32
alias HIDDEN = 768
alias HEADS = 12
alias HEAD_DIM = HIDDEN // HEADS  # Computed at compile time
```

## 3. SIMD and DType

### 3.1 DType -- Data Type Descriptors

`DType` represents numeric element types at the type level.

```mojo
# Common DTypes
DType.float16     # 16-bit float (half precision)
DType.bfloat16    # Brain floating point
DType.float32     # 32-bit float (single precision)
DType.float64     # 64-bit float (double precision)
DType.int8        # Signed 8-bit integer
DType.int16       # Signed 16-bit integer
DType.int32       # Signed 32-bit integer
DType.int64       # Signed 64-bit integer
DType.uint8       # Unsigned 8-bit integer
DType.uint32      # Unsigned 32-bit integer
DType.bool        # Boolean
DType.index       # Platform-native index type

# FP8 types for AI workloads
DType.float8e4m3  # 4-bit exponent, 3-bit mantissa
DType.float8e5m2  # 5-bit exponent, 2-bit mantissa

# Querying properties
alias dt = DType.float32
alias byte_width = dt.sizeof()     # 4
alias bit_width = dt.bitwidth()    # 32
```

### 3.2 SIMD -- Vectorized Operations

SIMD (Single Instruction, Multiple Data) is a first-class type providing hardware-vectorized operations.

```mojo
# SIMD[type, width] -- a vector of `width` elements of `type`
var v = SIMD[DType.float32, 4](1.0, 2.0, 3.0, 4.0)
var zeros = SIMD[DType.float32, 8](0)           # 8 zeros
var ones = SIMD[DType.float32, 16](1)           # 16 ones

# Scalar is just SIMD with width 1
alias Scalar = SIMD[type, 1]
var x: Scalar[DType.float32] = 3.14

# Arithmetic -- operates on all lanes simultaneously
var a = SIMD[DType.float32, 4](1.0, 2.0, 3.0, 4.0)
var b = SIMD[DType.float32, 4](5.0, 6.0, 7.0, 8.0)
var c = a + b        # [6.0, 8.0, 10.0, 12.0]
var d = a * b        # [5.0, 12.0, 21.0, 32.0]
var e = a.fma(b, c)  # Fused multiply-add: a*b + c

# Reductions
var total = a.reduce_add()   # Sum all lanes: 10.0
var maximum = a.reduce_max() # Max across lanes: 4.0

# Casting between types
var f16 = a.cast[DType.float16]()
var bf16 = a.cast[DType.bfloat16]()
var i32 = a.cast[DType.int32]()

# Querying system SIMD width for optimal vectorization
alias simd_width = simdwidthof[DType.float32]()  # e.g., 8 on AVX2
```

### 3.3 Vectorized Loops

```mojo
from algorithm import vectorize

# Process array in SIMD-width chunks (auto-tailing)
def vector_add(
    a: UnsafePointer[Float32],
    b: UnsafePointer[Float32],
    out: UnsafePointer[Float32],
    n: Int,
):
    alias width = simdwidthof[DType.float32]()

    @parameter
    def body[simd_width: Int](i: Int):
        var va = a.load[width=simd_width](i)
        var vb = b.load[width=simd_width](i)
        out.store(i, va + vb)

    vectorize[body, width](n)
```

## 4. Memory Management

### 4.1 UnsafePointer

The primary tool for manual memory management. You are responsible for allocation, initialization, and deallocation.

```mojo
from memory import UnsafePointer, memset_zero, memcpy, memset

# Allocate raw memory for 1024 Float32 values
var ptr = UnsafePointer[Float32].alloc(1024)

# Zero-initialize the block
memset_zero(ptr, 1024)

# Set all bytes to a specific value
memset(ptr, 0, 1024 * sizeof[Float32]())

# Read and write
ptr[0] = 3.14
var val = ptr[0]

# Pointer arithmetic
var offset_ptr = ptr + 512  # Points to element 512

# SIMD load/store through pointer
var vec = ptr.load[width=8](0)        # Load 8 floats starting at index 0
ptr.store(0, vec * SIMD[DType.float32, 8](2.0))  # Store scaled values back

# Copy memory between buffers
var dst = UnsafePointer[Float32].alloc(1024)
memcpy(dst, ptr, 1024)

# Free when done -- YOU are responsible for this
ptr.free()
dst.free()
```

### 4.2 Buffer and NDBuffer

Higher-level abstractions over raw pointers:

```mojo
# Buffer -- 1D contiguous memory with bounds
var buf = Buffer[DType.float32](ptr, 1024)
buf[0] = 1.0
var v = buf.load[width=4](0)  # SIMD load

# NDBuffer -- N-dimensional view over memory
# Shape is a compile-time parameter
var tensor = NDBuffer[DType.float32, 3](ptr, Index(batch, seq_len, hidden))
var element = tensor[0, 5, 128]  # Access [batch=0, seq=5, dim=128]
```

### 4.3 LayoutTensor

The highest-level abstraction for multi-dimensional data, with support for different memory layouts, address spaces, and GPU shared memory:

```mojo
# Stack-allocated shared memory tensor (GPU kernel)
var smem = LayoutTensor[
    DType.bfloat16,
    Layout.row_major(64, 64),
    AddressSpace.SHARED,
].stack_allocation()

# Copy data into shared memory tile
smem.copy(global_tensor_slice)

# Access elements
var val = smem[row, col]
```

### 4.4 Memory Safety Patterns (with Debug Instrumentation)

```mojo
# Pattern: RAII wrapper with full allocation tracking
struct ManagedBuffer(Debuggable):
    var ptr: UnsafePointer[Float32]
    var size: Int
    var _id: Int  # Unique buffer ID for debug tracking

    # Static counter for assigning unique IDs
    alias _next_id: Int = 0

    def __init__(out self, size: Int):
        self.size = size
        self._id = Self._next_id
        Self._next_id += 1
        self.ptr = UnsafePointer[Float32].alloc(size)
        memset_zero(self.ptr, size)
        DebugLog.info(
            "ManagedBuffer[" + str(self._id) + "] alloc "
            + str(size) + " floats at " + str(int(self.ptr))
        )

    def __moveinit__(out self, owned other: Self):
        self.ptr = other.ptr
        self.size = other.size
        self._id = other._id
        DebugLog.trace(
            "ManagedBuffer[" + str(self._id) + "] moved"
        )

    def __del__(owned self):
        if self.ptr:
            DebugLog.info(
                "ManagedBuffer[" + str(self._id) + "] free at "
                + str(int(self.ptr))
            )
            self.ptr.free()

    def __getitem__(self, i: Int) -> Float32:
        debug_assert(i >= 0 and i < self.size, "OOB read at index " + str(i))
        return self.ptr[i]

    def __setitem__(inout self, i: Int, val: Float32):
        debug_assert(i >= 0 and i < self.size, "OOB write at index " + str(i))
        self.ptr[i] = val

    # Debuggable trait conformance
    def debug_name(self) -> String:
        return "ManagedBuffer[" + str(self._id) + "]"

    def debug_dump(self):
        DebugLog.info(
            self.debug_name() + " size=" + str(self.size)
            + " ptr=" + str(int(self.ptr))
        )
```

## 5. Decorators and Compile-Time Control

### 5.1 Key Decorators

| Decorator | Purpose | When to Use |
|:----------|:--------|:------------|
| `@always_inline` | Force inlining | Hot inner loops, SIMD helpers |
| `@always_inline("nodebug")` | Inline without debug info | Wrapper functions |
| `@parameter` | Parametric closure | Passing compile-time specialized lambdas |
| `@register_passable` | Pass in CPU registers | Small value types (coordinates, colors) |
| `@register_passable("trivial")` | Trivial register type | Types with no lifecycle methods |
| `@__llvm_metadata` | Set LLVM/GPU metadata | GPU cluster shapes, launch params |
| `@value` | Auto-generate lifecycle | Quick structs that need copy/move/init |

```mojo
# @always_inline -- eliminate call overhead
@always_inline
def relu(x: Float32) -> Float32:
    return x if x > 0.0 else 0.0

# @register_passable -- pass small types in registers
@register_passable("trivial")
struct Vec2:
    var x: Float32
    var y: Float32

# @value -- auto-generate __init__, __copyinit__, __moveinit__
@value
struct Point:
    var x: Int
    var y: Int
    # All lifecycle methods generated automatically
```

### 6.3 FFI Bridge Pattern (from iTaK) -- with Debug Instrumentation

Pattern for wrapping a C shared library (e.g., llama.cpp) with zero-overhead function pointers. Every symbol resolution and FFI call is logged:

```mojo
struct LlamaEngine(Debuggable):
    """Mojo wrapper around llama.cpp shared library using direct FFI."""
    var handle: DLHandle
    var _model_load: fn(UnsafePointer[UInt8], Int) -> UnsafePointer[NoneType]
    var _generate: fn(UnsafePointer[NoneType], UnsafePointer[UInt8], Int) -> Int
    var _free: fn(UnsafePointer[NoneType]) -> NoneType
    var _lib_path: String

    def __init__(out self, lib_path: String) raises:
        DebugLog.info("[FFI] Loading shared library: " + lib_path)
        self._lib_path = lib_path
        self.handle = DLHandle(lib_path)
        DebugLog.info("[FFI] Library handle acquired")

        DebugLog.trace("[FFI] Resolving symbol: llama_model_load")
        self._model_load = self.handle.get_function[
            fn(UnsafePointer[UInt8], Int) -> UnsafePointer[NoneType]
        ]("llama_model_load")
        DebugLog.trace("[FFI] Resolved: llama_model_load")

        DebugLog.trace("[FFI] Resolving symbol: llama_generate")
        self._generate = self.handle.get_function[
            fn(UnsafePointer[NoneType], UnsafePointer[UInt8], Int) -> Int
        ]("llama_generate")
        DebugLog.trace("[FFI] Resolved: llama_generate")

        DebugLog.trace("[FFI] Resolving symbol: llama_model_free")
        self._free = self.handle.get_function[
            fn(UnsafePointer[NoneType]) -> NoneType
        ]("llama_model_free")
        DebugLog.trace("[FFI] Resolved: llama_model_free")

        DebugLog.info("[FFI] LlamaEngine ready (" + lib_path + ")")

    def load_model(inout self, path_ptr: UnsafePointer[UInt8], path_len: Int) -> UnsafePointer[NoneType]:
        DebugLog.info("[FFI] llama_model_load called")
        var result = self._model_load(path_ptr, path_len)
        DebugLog.info("[FFI] llama_model_load returned ptr=" + str(int(result)))
        debug_assert(int(result) != 0, "llama_model_load returned NULL")
        return result

    def generate(inout self, model: UnsafePointer[NoneType], prompt: UnsafePointer[UInt8], len: Int) -> Int:
        DebugLog.info("[FFI] llama_generate called, prompt_len=" + str(len))
        var tokens = self._generate(model, prompt, len)
        DebugLog.info("[FFI] llama_generate produced " + str(tokens) + " tokens")
        return tokens

    def __del__(owned self):
        DebugLog.info("[FFI] Closing library handle: " + self._lib_path)
        self.handle.close()

    # Debuggable trait
    def debug_name(self) -> String:
        return "LlamaEngine(" + self._lib_path + ")"

    def debug_dump(self):
        DebugLog.info(self.debug_name() + " -- handle open")
```

## 7. GPU Programming

### 7.1 Kernel Basics

Mojo GPU kernels compile through MLIR, targeting NVIDIA (PTX) and AMD (AMDGPU) backends.

```mojo
# Simple vector addition kernel
def vector_add_kernel(
    a_ptr: UnsafePointer[Scalar[DType.float32]],
    b_ptr: UnsafePointer[Scalar[DType.float32]],
    c_ptr: UnsafePointer[Scalar[DType.float32]],
    n: Int,
):
    var idx = ThreadIdx.x() + BlockDim.x() * BlockIdx.x()
    if idx < n:
        c_ptr[idx] = a_ptr[idx] + b_ptr[idx]
```

### 7.2 Grid Stride Loops

Handle arbitrary-length data with a fixed grid:

```mojo
def kernel_grid_stride(
    a_ptr: UnsafePointer[Scalar[DType.float32]],
    b_ptr: UnsafePointer[Scalar[DType.float32]],
    n: Int,
):
    var idx = ThreadIdx.x() + BlockDim.x() * BlockIdx.x()
    for i in range(idx, n, BlockDim.x() * GridDim.x()):
        b_ptr[i] = a_ptr[i]
```

### 7.3 Vectorized GPU Loads/Stores

```mojo
def copy_vectorized[simd_size: Int, align: Int](
    src: UnsafePointer[Scalar[DType.float32]],
    dst: UnsafePointer[Scalar[DType.float32]],
    n: Int,
):
    var idx = ThreadIdx.x() + BlockDim.x() * BlockIdx.x()
    var a = Buffer[DType.float32](src, n)
    var b = Buffer[DType.float32](dst, n)
    for i in range(idx, n // simd_size, BlockDim.x() * GridDim.x()):
        b.store[alignment=align](
            i * simd_size,
            a.load[width=simd_size, alignment=align](i * simd_size),
        )
```

### 7.4 Shared Memory and Tiling

```mojo
def tiled_matmul_kernel(
    a_ptr: UnsafePointer[Scalar[DType.bfloat16]],
    b_ptr: UnsafePointer[Scalar[DType.bfloat16]],
    c_ptr: UnsafePointer[Scalar[DType.float32]],
):
    # Allocate tiles in shared memory
    var a_tile = LayoutTensor[
        DType.bfloat16,
        Layout.row_major(64, 64),
        AddressSpace.SHARED,
    ].stack_allocation()

    var b_tile = LayoutTensor[
        DType.bfloat16,
        Layout.row_major(64, 64),
        AddressSpace.SHARED,
    ].stack_allocation()

    var accum = Scalar[DType.float32](0.0)

    alias K = 4096
    alias TILE = 64
    for k in range(0, K, TILE):
        # Cooperative load into shared memory
        a_tile.copy(...)
        b_tile.copy(...)
        barrier()

        # Compute on shared memory tile
        for kk in range(TILE):
            accum += a_tile[ThreadIdx.y(), kk].cast[DType.float32]()
                   * b_tile[kk, ThreadIdx.x()].cast[DType.float32]()
        barrier()

    # Write accumulated result to global memory
    c_ptr[ThreadIdx.y() * 64 + ThreadIdx.x()] = accum
```

### 7.5 TMA (Tensor Memory Accelerator) -- Hopper/Blackwell

```mojo
# Create TMA descriptors for async copies
var a_tma = create_tma_tile[Index(BM, BK)](ctx, a_global_addr)
var b_tma = create_tma_tile[Index(BN, BK)](ctx, b_global_addr)

# Async copy with barrier synchronization
alias num_iters = K // BK
for i in range(num_iters):
    if elect_one_thread:
        tma_mbar[0].expect_bytes(expected_bytes)
        a_tma.async_copy(a_smem_tile, tma_mbar[0], (i * BK, block_y * BM))
        b_tma.async_copy(b_smem_tile, tma_mbar[0], (i * BK, block_x * BN))
    tma_mbar[0].wait(tma_phase)
    tma_phase ^= 1
```

## 8. GGUF Model Handling

### 8.1 GGUF Binary Format Parsing

GGUF is a little-endian binary format. Parsing it requires careful pointer-based reading:

```mojo
struct GGUFHeader:
    """GGUF file header -- first bytes of every .gguf file."""
    var magic: UInt32          # 0x46475547 ("GGUF" in LE)
    var version: UInt32        # Format version (2 or 3)
    var tensor_count: UInt64   # Number of tensors in the file
    var metadata_kv_count: UInt64  # Number of metadata key-value pairs

struct GGUFParser(Debuggable):
    var data: UnsafePointer[UInt8]
    var offset: Int
    var file_size: Int

    def __init__(out self, data: UnsafePointer[UInt8], size: Int):
        self.data = data
        self.offset = 0
        self.file_size = size
        DebugLog.info("[GGUF] Parser initialized, file_size=" + str(size) + " bytes")

    def read_u32(inout self) -> UInt32:
        """Read a little-endian UInt32 and advance offset."""
        debug_assert(
            self.offset + 4 <= self.file_size,
            "[GGUF] OOB read_u32 at offset " + str(self.offset)
        )
        var val = self.data.offset(self.offset).bitcast[UInt32]()[0]
        DebugLog.trace("[GGUF] read_u32 @" + str(self.offset) + " = " + str(val))
        self.offset += 4
        return val

    def read_u64(inout self) -> UInt64:
        debug_assert(
            self.offset + 8 <= self.file_size,
            "[GGUF] OOB read_u64 at offset " + str(self.offset)
        )
        var val = self.data.offset(self.offset).bitcast[UInt64]()[0]
        DebugLog.trace("[GGUF] read_u64 @" + str(self.offset) + " = " + str(val))
        self.offset += 8
        return val

    def read_string(inout self) -> String:
        """GGUF strings are length-prefixed (u64 length, then bytes)."""
        var length = self.read_u64()
        debug_assert(
            self.offset + int(length) <= self.file_size,
            "[GGUF] OOB read_string, len=" + str(length) + " at offset " + str(self.offset)
        )
        var str_ptr = self.data.offset(self.offset)
        self.offset += int(length)
        var result = String(str_ptr, int(length))
        DebugLog.trace("[GGUF] read_string: '" + result + "'")
        return result

    def parse_header(inout self) raises -> GGUFHeader:
        DebugLog.info("[GGUF] Parsing header...")
        var magic = self.read_u32()
        if magic != 0x46475547:
            DebugLog.error("[GGUF] Bad magic: 0x" + hex(magic) + " (expected 0x46475547)")
            raise Error("not a GGUF file (bad magic)")
        var header = GGUFHeader(
            magic=magic,
            version=self.read_u32(),
            tensor_count=self.read_u64(),
            metadata_kv_count=self.read_u64(),
        )
        DebugLog.info(
            "[GGUF] Header OK: v" + str(header.version)
            + ", tensors=" + str(header.tensor_count)
            + ", kv_pairs=" + str(header.metadata_kv_count)
        )
        return header

    # Debuggable trait
    def debug_name(self) -> String:
        return "GGUFParser"

    def debug_dump(self):
        DebugLog.info(
            "[GGUF] offset=" + str(self.offset)
            + "/" + str(self.file_size)
            + " (" + str((self.offset * 100) // self.file_size) + "% consumed)"
        )
```

### 9.4 Mojo GPU Kernels with LayoutTensor

LayoutTensor is how Mojo talks to GPU memory. It encodes the shape, stride, and data type at compile time so the compiler can map your indexing straight to hardware addresses with zero overhead.

**Basic matmul kernel (4 lines that map to the silicon):**

```mojo
fn matmul_kernel[
    M: Int, N: Int, K: Int
](
    c: LayoutTensor[DType.bfloat16, Layout.row_major(M, N)],
    a: LayoutTensor[DType.bfloat16, Layout.row_major(M, K)],
    b: LayoutTensor[DType.bfloat16, Layout.row_major(N, K)],
):
    """Each thread computes one element of C. Threads map 1:1 to output elements."""
    var acc = Float32(0)
    for k in range(K):
        acc += a[global_idx.y, k].cast[DType.float32]() *
               b[global_idx.x, k].cast[DType.float32]()
    c[global_idx.y, global_idx.x] = acc.cast[DType.bfloat16]()
```

**Shared memory tiled matmul (talks to SMEM, not just global):**

```mojo
# Each thread block loads tiles from A and B into shared memory
var a_smem = LayoutTensor[..., AddressSpace.SHARED].stack_allocation()
var b_smem = LayoutTensor[..., AddressSpace.SHARED].stack_allocation()

var accum = Scalar[DType.bfloat16](0.0)

alias tile_size = 32
for k in range(0, K, tile_size):
    # Load from global memory (GMEM) to shared memory (SMEM)
    a_smem.copy(...)
    b_smem.copy(...)

    # Barrier: ensure all threads finished writing to SMEM
    barrier()

    @parameter
    for kk in range(tile_size):
        accum += a_smem[i, kk] * b_smem[kk, j]

    # Barrier: ensure all threads finished reading from SMEM
    barrier()
```

### 9.5 TMA (Tensor Memory Accelerator) -- Hopper/Blackwell

TMA is a dedicated hardware unit that moves multi-dimensional tiles between global and shared memory asynchronously. Instead of each thread calculating addresses, TMA transfers entire tensor tiles in one instruction.

```mojo
# Host-side: create TMA tile descriptors

b_tma_op = create_tma_tile[Index(BN, BK)](ctx, b_global_mem_address)

# Kernel-side: async copy from GMEM to SMEM via TMA
# Only the leader thread issues the copy; hardware handles the transfer
tma_async_load(a_smem_ptr, a_tma_op, tile_coords)
```

### 9.6 Tensor Core MMA (Matrix Multiply-Accumulate)

Tensor cores are specialized units inside each SM that perform matrix-multiply-accumulate in a single instruction. A CUDA core does one FMA per clock; a tensor core does an entire 64x128 tile MMA.

## 10. Token Sampling Implementations

### 10.1 Greedy Sampling

```mojo
def greedy_sampling(logits: UnsafePointer[Float32], vocab_size: Int) -> Int:
    """Select the token with the highest logit (argmax)."""
    var max_val = logits[0]
    var max_idx: Int = 0
    for i in range(1, vocab_size):
        if logits[i] > max_val:
            max_val = logits[i]
            max_idx = i
    return max_idx
```

### 10.2 Top-K Sampling

```mojo
def top_k_sampling(
    logits: UnsafePointer[Float32],
    vocab_size: Int,
    k: Int,
    temperature: Float32,
) -> Int:
    """Sample from the top-k most probable tokens with temperature scaling."""
    # 1. Apply temperature
    for i in range(vocab_size):
        logits[i] /= temperature

    # 2. Find top-k indices (partial sort)
    var top_indices = UnsafePointer[Int].alloc(k)
    var top_values = UnsafePointer[Float32].alloc(k)
    # ... partial sort logic ...

    # 3. Softmax over top-k
    var max_val = top_values[0]
    var sum_exp: Float32 = 0.0
    for i in range(k):
        top_values[i] = exp(top_values[i] - max_val)
        sum_exp += top_values[i]
    for i in range(k):
        top_values[i] /= sum_exp

    # 4. Sample from distribution
    var r = random_float32()  # Uniform [0, 1)
    var cumsum: Float32 = 0.0
    for i in range(k):
        cumsum += top_values[i]
        if cumsum >= r:
            var result = top_indices[i]
            top_indices.free()
            top_values.free()
            return result

    var result = top_indices[k - 1]
    top_indices.free()
    top_values.free()
    return result
```

## 11. Performance Optimization Patterns

### 11.1 Tiling for Cache Locality

```mojo
alias TILE_M = 64
alias TILE_N = 64
alias TILE_K = 32

def tiled_gemm(
    A: UnsafePointer[Float32],  # M x K
    B: UnsafePointer[Float32],  # K x N
    C: UnsafePointer[Float32],  # M x N
    M: Int, N: Int, K: Int,
):
    for i0 in range(0, M, TILE_M):
        for j0 in range(0, N, TILE_N):
            for k0 in range(0, K, TILE_K):
                # Inner tile -- fits in L1/L2 cache
                for i in range(i0, min(i0 + TILE_M, M)):
                    for k in range(k0, min(k0 + TILE_K, K)):
                        var a_val = A[i * K + k]
                        for j in range(j0, min(j0 + TILE_N, N)):
                            C[i * N + j] += a_val * B[k * N + j]
```

## 12. Common Compiler Errors and Solutions

### 12.1 Type Mismatch

```
error: cannot implicitly convert 'Int32' to 'Int'
```
**Fix:** Use explicit casting: `Int(my_int32_val)`

### 12.2 Failed to Infer Parameter

```
error: failed to infer parameter 'T' for function 'process'
```
**Fix:** Provide explicit parameter: `process[Float32](data)`

### 12.3 Lifetime / Origin Errors

```
error: reference outlives its owner
```
**Fix:** Ensure the variable that owns the data lives at least as long as any reference to it. Mojo uses ASAP destruction. Store a copy if needed.

### 12.4 Missing Lifecycle Method

```
error: type 'MyType' does not implement '__copyinit__'
```
**Fix:** Either implement `__copyinit__` or use the `@value` decorator to auto-generate it.

### 12.5 SIMD Width Mismatch

```
error: invalid SIMD width '7', must be a power of 2
```
**Fix:** SIMD widths must be powers of 2 (1, 2, 4, 8, 16, 32...).

### 12.6 Raises Annotation Missing

```
error: function may raise but is not marked with 'raises'
```
**Fix:** Add `raises` to the function signature: `def load(path: String) raises -> Model:`

### 12.7 Mutable Self in Method

```
error: cannot mutate 'self' -- parameter is borrowed
```
**Fix:** Use `inout self` in the method signature: `def update(inout self, val: Int):`

### 12.8 Cannot Use Value After Transfer

```
error: use of moved value 'buffer'
```
**Fix:** The value was transferred with `^`. You cannot use it after transfer. Create a copy before transferring if you need both.

### 12.9 Large-Function Compiler Bugs (LLVM/MLIR Hang)

```
error: Process killed (OOM) or Compiler hangs indefinitely
```
**Fix:** The Mojo compiler's backend (MLIR/LLVM) currently struggles with massive functions, deep nesting, and monolithic processing blocks (e.g., a single 500-line `run_inference` function). 

**Mandatory Refactoring Practices (for Cleaner, Resilient Code):**
1. **Split Monoliths:** Break large functions into smaller, modular helper functions (`def parse_headers()`, `def load_tensors()`, `def execute_layer()`). Never write a function over 100 lines.
2. **Aggressive Inlining:** Use `@always_inline` on these small helper functions. The compiler paradoxically handles many small strictly-inlined functions much better than one giant block of raw code.
3. **Struct Encapsulation:** Instead of passing 15 arguments around, pack state into structs (`struct InferenceContext`) and use methods. This reduces register pressure and variable tracking complexity.
4. **Early Returns & Flat Control Flow:** Deeply nested `if/else` ladders exponentially increase the compiler's control flow graph (CFG) analysis time. Use early returns, `raise`, and break out of loops as early as possible.
5. **Tight Variable Scopes:** Declare variables exactly where they are used, not at the top of the function. This minimizes their active lifetime and reduces compile-time memory footprint.

### 13.4 Memory Allocation Tracker

```mojo
struct MemoryTracker:
    """Tracks all allocations to detect leaks and double-frees.
    Only active when DEBUG=True."""
    var alloc_count: Int
    var free_count: Int
    var total_bytes: Int

    def __init__(out self):
        self.alloc_count = 0
        self.free_count = 0
        self.total_bytes = 0

    def track_alloc(inout self, ptr_val: Int, size_bytes: Int, tag: String):
        comptime if DEBUG:
            self.alloc_count += 1
            self.total_bytes += size_bytes
            DebugLog.memory("ALLOC [" + tag + "]", ptr_val, size_bytes)

    def track_free(inout self, ptr_val: Int, size_bytes: Int, tag: String):
        comptime if DEBUG:
            self.free_count += 1
            self.total_bytes -= size_bytes
            DebugLog.memory("FREE  [" + tag + "]", ptr_val, size_bytes)

    def report(self):
        """Call at program exit to check for leaks."""
        comptime if DEBUG:
            DebugLog.info("--- Memory Report ---")
            DebugLog.info("  Allocations: " + str(self.alloc_count))
            DebugLog.info("  Frees:       " + str(self.free_count))
            DebugLog.info("  Outstanding: " + str(self.alloc_count - self.free_count))
            DebugLog.info("  Held bytes:  " + str(self.total_bytes))
            if self.alloc_count != self.free_count:
                DebugLog.error(
                    "LEAK DETECTED: " + str(self.alloc_count - self.free_count)
                    + " allocations not freed"
                )

# Global tracker instance
var g_mem_tracker = MemoryTracker()
```

### 13.5 GPU Kernel Debug Helpers

```mojo
# Always log before launching any GPU kernel
def launch_kernel_debug[
    kernel_name: StringLiteral,
](
    grid_dim: Int,
    block_dim: Int,
    shared_mem: Int,
):
    """Wraps kernel launch with pre-flight debug logging."""
    DebugLog.gpu(kernel_name, grid_dim, block_dim, shared_mem)
    debug_assert(grid_dim > 0, kernel_name + ": grid_dim must be > 0")
    debug_assert(block_dim > 0, kernel_name + ": block_dim must be > 0")
    debug_assert(block_dim <= 1024, kernel_name + ": block_dim exceeds 1024")
    debug_assert(
        shared_mem <= 163840,  # 160KB limit on Hopper
        kernel_name + ": shared_mem exceeds 160KB limit"
    )

# Example usage before kernel dispatch:
# launch_kernel_debug["tiled_matmul"](num_blocks, 256, 64 * 64 * 2)
```

### 13.6 Build Profiles

```bash
# DEVELOPMENT: Full debug, no optimization, stack traces
set MOJO_ENABLE_STACK_TRACE_ON_ERROR=1
set MOJO_LOG_LEVEL=TRACE
mojo build myfile.mojo --debug-level=full -O0

# PROFILING: Debug symbols + optimization (for perf investigation)
mojo build myfile.mojo --debug-level=line-tables -O2

# RELEASE: Strip everything, max speed
# Change alias DEBUG: Bool = False in source, then:
mojo build myfile.mojo -O3
```
