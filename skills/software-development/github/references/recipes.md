# Recipes: The Six Core Workflows in One Page

Short recipes for the six workflows this skill routes most often.
Each recipe is a pointer with the load-bearing commands; the full
discipline lives in the named reference, which is read first.

| Recipe | Read first | Shape |
|---|---|---|
| Auth setup | `references/auth-and-identity.md` | `gh auth login`, `gh auth setup-git`, read back with `gh auth status` |
| Issue triage | `references/issues.md` | duplicate sweep, label, assign, read back |
| PR lifecycle | `references/pr-workflow.md` | branch, commit, PR, `gh pr checks`, merge after confirmation |
| Issue to PR | `references/issue-to-pr.md` | read the full thread, validate the premise, smallest change, verified PR |
| Code review | `references/code-review.md` | context read, inline comments in the output template shape, verdict |
| Repo management | `references/repo-management.md` | view, create, settings under the never-list, releases via `references/releases.md` |

Every recipe ends the same way: a fresh `gh` read that proves the
state the recipe claims.
